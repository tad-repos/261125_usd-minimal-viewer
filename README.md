# USD Minimal Viewer

Browser-based viewer for local USD files, with tessellated USD BRep preview, object inspection, material display and multiple-file opening. Exact BRep support is limited to self-contained ASCII USDA; ordinary USD rendering supports a subset of the format.

[Launch app](https://tad-repos.github.io/261125_usd-minimal-viewer/)

Develop locally with Node.js 22.18+: `npm install`, then `npm run dev`. Build with `npm run build`.
